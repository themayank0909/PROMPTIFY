## 🌟 Key Highlights & Features

### 1. 🔴 Interactive Live Classes (PW Style)
- Ultra-low latency video player HUD with 1080p 60fps indicator and real-time student viewer counter.
- **Split-View Mode**: Simultaneous view of Mayank Sir's live camera and the live coding editor.
- **Live Doubts Box**: Dedicated questions box where students submit technical doubts and upvote peers for live whiteboard explanations.
- **Instant Live Polls & Quizzes**: Live interactive polling with real-time percentage distribution.
- **Lecture Annotations & DPP Sheets**: Downloadable PDF notes and Daily Practice Problems for every session.

### 2. 🐍 Python 3.10 Interactive Lab & Sandbox
- **Real Server-Side Python 3 Execution**: Run Python scripts directly with sub-100ms response times.
- **Structured Python Curriculum**:
  - Fundamentals & modern f-strings
  - List & dictionary comprehensions
  - LeetCode DSA in Python (Two Pointers, Graphs, Hash Maps)
  - Object-Oriented Python (`__init__`, `__repr__`, `@property`)
  - Python for GenAI (Cosine similarity & Vector embeddings math)
- **AI Code Review**: One-click code diagnosis powered by CodeGuru AI.

### 3. 🌿 SAATHI (साथी) — Mental Wellness & Anti-Distraction Mentor
- **Empathetic AI Companion**: Formulated to combat student loneliness, placement anxiety, burnout, and social media addiction.
- **Water Bubble Pomodoro Focus Timer**: 25m/5m cycles with soothing animated liquid pulse.
- **Synthesized Ambient Soundscapes**: Rain, ocean, and lo-fi focus beats generated via Web Audio API without external asset dependencies.
- **Mayank Sir’s Motivational Voice Notes**: Interactive wisdom clips with audio waveforms.
- **Student SOS Support**: Quick access to national mental health helpline services.

### 4. 🤖 CodeGuru AI Doubt Solver
- 24/7 intelligent code debugger and Big-O algorithm optimizer powered by Google Gemini 3.8 Flash.
- Preset workflows: *Debug & Fix Bugs*, *Optimize Time & Space*, *Explain Line-by-Line*, and *Interview Follow-ups*.

### 5. 🔥 Daily Attendance, Streaks & CodeCoins
- One-click daily punch-in with streak counter (`14-Day Streak`).
- Visual monthly attendance calendar.
- **CodeCoins Redemption Store**: Redeem earned attendance coins for 1-on-1 mock interview coupons and handwritten system design cheatsheets.

### 6. 🤝 1-on-1 Mentor Connect
- Book sessions with Mayank Sir and Staff Software Engineers from Google, Microsoft, and Stripe.
- Interactive live mentorship room simulation with video feeds and real-time collaborative scratchpad.

### 7. 🎨 2026 Liquid Mac Water Bubble Design
- Interactive HTML5 Canvas fluid simulation with organic floating bubbles, specular refraction sheens, and mouse-repelling inertia.
- Sleek macOS dark theme (`#040711`), frosted glass morphism (`backdrop-blur-2xl`), and traffic-light window controls (`🔴 🟡 🟢`).
